# AI Endless Battler

A text game with OpenAI implementation. You start off facing 'A Measly Worm' and must name something that beats it, you then face what you used in the previous round. The goal is to get as many wins as possible in a row.

This is a Single Page Application. It uses Node.js on the backend and React for the frontend. As well as OpenAI to determine the victor and reason why.
